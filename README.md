# Tamweel Lite
amweel Lite | Simplified Financing Project

Project Scenario

Tamweel Lite simulates a financing institution that receives customer loan applications and aims to leverage machine learning techniques to estimate the probability of a customer experiencing credit default within 90 days of the application date.

The system relies exclusively on information available at the time of application to prevent data leakage and ensure reliable predictions. It analyzes each application to generate a credit risk score and provide a recommendation for additional review based on the estimated risk level, the cost of prediction errors, and the review team’s available capacity.

The project is designed to support decision-making and improve the efficiency of credit risk assessment while keeping final decisions under human supervision. The system does not automatically approve or reject applications.

**Developer:** Raghad Aldawsari
**Project type:** Individual capstone project



## Project overview

Tamweel Lite is a machine learning project for credit-risk prediction in a simulated financing environment. The solution estimates the likelihood of customer default within 90 days of application using only information available at submission time. The workflow includes data validation, feature preparation, model training, ensemble learning, probability calibration, threshold optimization, explainability analysis, fairness monitoring, and final prediction generation. The system supports risk-assessment decisions by providing risk scores and review recommendations while keeping final decisions under human oversight.
